⏺ Short answer

  No domain allowlisting is needed. That requirement belongs to a different
  (older, Snapchat-only) pattern where RemoteServiceModule required picking a
  specific whitelisted API/domain from the Asset Library's "Remote APIs"
  catalog. For Specs, since Lens Studio 5.9, fetch/performHttpRequest moved to
  InternetModule, which does open HTTPS fetch to any domain — there's no
  per-domain allowlist screen in Project Settings for it.

  What's actually needed

  1. Module access — no manual asset wiring. Use:
  private internetModule: InternetModule = require('LensStudio:InternetModule')
  1. require('LensStudio:InternetModule') pulls the system module directly; you
  don't drag anything into the Resources panel.
  2. HTTPS required for publishing — your URL
  (https://fantasyfootballcalculator.com/...) already qualifies. Plain http://
  would need "Allow Experimental API" in Project Settings, and Lenses using it
  can't be published.
  3. Preview testing — the Fetch API only works in the Preview panel when Device
  Type Override = Spectacles/SPECS 27. Otherwise every request 404s. I checked
  and confirmed your project currently has no InternetModule asset and no
  scripts yet, so this'll be a fresh setup.
  4. Privacy tradeoff — enabling internet access disables camera frame,
  location, and mic access in that Lens (unless you also enable Extended
  Permissions, which is prototype/testing-only and blocks public release). Worth
  flagging in case SPECS Lens also wants camera features later.

  Fetch pattern for this endpoint

  @component
  export class AdpFetcher extends BaseScriptComponent {
    private internetModule: InternetModule =
  require('LensStudio:InternetModule')

    onAwake(): void {
      this.fetchAdp()
    }

    private async fetchAdp(): Promise<void> {
      try {
        const response = await this.internetModule.fetch(
          'https://fantasyfootballcalculator.com/api/v1/adp/standard?teams=12&ye
  ar=2026&position=all',
          { method: 'GET' }
        )
        if (response.status !== 200) {
          print('[ADP] HTTP error: ' + response.status)
          return
        }
        const json = await response.json()
        print('[ADP] Loaded ' + json.players?.length + ' players')
      } catch (err) {
        print('[ADP] Fetch failed: ' + err)
      }
    }
  }
